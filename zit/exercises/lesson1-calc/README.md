# תרגיל הפתיחה של מפגש 1: Calc בלי git

17 דקות, לפני שמזכירים את המילה git. שלישיות, קובץ Java אחד, וכל אחד משלים בו פונקציה. הפונקציות בנויות זו על זו: `mul` משתמשת ב-`add`, ו-`power` משתמשת ב-`mul`. כך אי אפשר לבדוק את החלק שלך בלי הקוד של חבר. מסנכרנים בוואטסאפ או בדרייב, איך שרוצים.

ההוראות המלאות, עם ההודעה של ראש הצוות בדקה 7 והשאלות לדיון, נמצאות ב[מערך של מפגש 1](../../plan/01-lesson1.md).

| קובץ | מה הוא |
| --- | --- |
| `Calc.java` | הקובץ שכולם מקבלים בתחילת התרגיל |
| `solution/Calc.java` | מה שהצוות היה אמור להגיש: מדפיס 5, 12 ו-32 |

```
javac Calc.java && java Calc
```

מה רואים בהרצה, לפי מה שנבדק:

| מצב | פלט |
| --- | --- |
| שלוש הפונקציות באותו קובץ | `5`, `12`, `32` |
| עותק שחסרה בו `add` | `0`, `0`, `0`, גם כש-`mul` ו-`power` נכונות |
| `add` הפכה ל-`sum`, ו-`mul` עדיין קוראת ל-`add` | `error: cannot find symbol` |
