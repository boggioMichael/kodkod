# מחקר: כלים קיימים

שום כלי קיים לא עושה בדיוק את zit, אבל כל אחד מהם פתר חלק מהבעיה. כל חבר חוקר כלי אחד ומוסיף שורה.

| כלי | מי חקר | הרעיון המרכזי | מה לקחנו ממנו |
| --- | --- | --- | --- |

כלים להתחיל מהם:

- [git-annex](https://git-annex.branchable.com/): מעקב אחרי "מי מחזיק מה"
- [Git LFS](https://git-lfs.com/): קובץ מצביע קטן ב-git, והתוכן בשרת
- [partial clone](https://git-scm.com/docs/partial-clone): הורדה עצלה, והמגבלות של שרת אחד
- [Scalar](https://git-scm.com/docs/scalar): איך git עצמו מתמודד עם ריפו ענק
- [IPFS](https://docs.ipfs.tech/concepts/content-addressing/): חלוקה לבלוקים, ואימות לפי hash
- [filter ב-gitattributes](https://git-scm.com/docs/gitattributes): ‏`clean` ו-`smudge`, נקודת חיבור למימוש zit מעל git רגיל
